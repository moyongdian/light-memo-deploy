# 变量模板

从备忘录页右上角进入「模板库」，新建模板并填写模板名称、备忘录标题、标签和正文。模板名称仅用于管理，不会成为生成的备忘录字段。

例如：

- 模板名称：每日任务
- 备忘录标题：`任务 · {{task_name}}`
- 标签：`{{project}}`
- 正文：`今天的任务是{{task_name}}`

保存后点击「使用模板」，填写 `task_name` 为「整理资料」、`project` 为「工作」。检查实时预览后点击「创建备忘录」，即可生成标题为「任务 · 整理资料」、标签为「工作」、正文为「今天的任务是整理资料」的独立备忘录。返回备忘录列表即可继续编辑。

模板库支持按名称、标题、正文搜索，以及分页、编辑和删除。删除模板需要确认；修改或删除模板不会修改已经生成的备忘录。退出未保存的模板或未完成的变量表单时会提示确认。

## 表达式规则

- 标题、标签和正文均支持 `{{变量名}}`，表达式内部首尾空白会忽略，例如 `{{ task_name }}`。
- 变量名区分大小写，以 Unicode 字母（包括中文）或下划线开头，其余字符可以是字母、数字或下划线，最长 64 个字符。每个模板最多 50 个不同变量。
- 同名变量只需填写一次，所有出现位置都会替换。没有变量的模板也可直接创建备忘录。
- 仅进行一次文本替换，不执行 JavaScript、HTML、函数或嵌套表达式。变量值包含 `{{另一变量}}` 时保留原文，不再次求值。
- 不匹配的双花括号、空变量名、点号或运算表达式会阻止保存。不支持转义双花括号。
- API 必须提供全部变量，且不能携带额外变量。可显式传空字符串，但替换后的标题必须非空。界面中输入后清空表示显式空值。
- 模板名称最多 100 个字符。模板及生成结果均遵守备忘录限制：标题 1–200 个字符、最多 20 个标签且每个最多 32 个字符、正文最多 128 KiB UTF-8。标签会去空白、去空项并去重。
- 填写期间其他窗口修改了模板，创建会返回版本冲突；重新加载模板后按最新变量重新填写。

## API

以下路径均以 `/api/v1` 开头，要求已登录；写请求和预览请求沿用 JSON、`X-Memo-CSRF: 1` 校验。

| 方法与路径 | 用途 |
| --- | --- |
| `GET /templates?q=&limit=30&offset=0` | 查询模板，limit 为 1–100 |
| `POST /templates` | 创建模板，返回 201 |
| `GET /templates/{id}` | 获取模板及变量列表、版本 |
| `PUT /templates/{id}` | 更新模板，版本递增 |
| `DELETE /templates/{id}` | 删除模板，返回 204 |
| `POST /templates/{id}/preview` | 服务端验证并渲染，返回标题、标签、正文，不写入 |
| `POST /templates/{id}/instantiate` | 验证并创建独立备忘录，返回 201 和备忘录 |

创建、更新请求：

```json
{"name":"每日任务","title":"任务 · {{task_name}}","tags":["{{project}}"],"content":"今天的任务是{{task_name}}"}
```

预览、实例化请求（version 使用读取到的模板版本）：

```json
{"version":1,"variables":{"task_name":"整理资料","project":"工作"}}
```

模板响应包含 `id`、`name`、`title`、`tags`、`content`、`variables`、`version`、`createdAt` 和 `updatedAt`。列表返回 `items` 和 `pagination`，结构与备忘录分页一致。

错误码包括 `INVALID_TEMPLATE`、`TEMPLATE_SYNTAX`、`TEMPLATE_VARIABLES`、`TEMPLATE_OUTPUT`（400）、`TEMPLATE_NOT_FOUND`（404）、`TEMPLATE_CHANGED`（409）。生成失败不会写入备忘录；重复主动提交会生成不同实例。

## 数据升级

新增嵌入迁移 `002_templates.sql`，建立独立的 `memo_templates` 表。更新后正常启动后端即可自动迁移已有数据库，无需重新 `init`。原有备忘录、认证和会话保留。模板不进入备忘录全文索引，实例化成功后新备忘录由既有触发器自动加入索引。
