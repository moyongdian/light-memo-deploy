# Memo 实现约定

初始需求见 [PLAN.md](PLAN.md)，本文件记录后续实现约定；运行与配置见 [GUIDE.md](GUIDE.md)。

- `title` 按 Unicode 码点计数 1–200，纯空白标题拒绝；保留标题原文。
- `tags` trim、删除空值、大小写敏感去重后最多 20 个，各 1–32 码点。
- `content` 原样保存，最多 131072 个 UTF-8 字节。正文允许为空。
- 密码 1–4096 UTF-8 字节；首次设置必须通过交互终端读取两次，不接受参数或环境变量。
- 搜索词最多 200 码点，标签过滤最多 32 码点；offset 0–2147483647。分页默认 30，最多 100。
- LIKE 回退转义 `%`、`_`、`\`；FTS 使用双引号 literal phrase，内部双引号加倍。搜索词不会被 trim。
- 结果排序末尾增加 ID 降序，确保相同毫秒时间的分页稳定。
- `GET /api/v1/tags` 返回 `{items:[{name,count}]}`，按 count DESC、name ASC 排序。
- 修改密码请求为 `{currentPassword,newPassword}`；确认密码由前端校验。
- 业务异常返回统一 JSON error；密码错误统一 `Invalid password`。

## GET 只读与滑动会话

PLAN 第 19 节的每次认证续期与第 23 节的 GET/HEAD 严格只读相冲突。实现保持 GET/HEAD 只读，增加 `POST /api/v1/auth/session`：需要认证、JSON Content-Type 和 `X-Memo-CSRF: 1`；剩余有效期小于 7 天时将数据库和 Cookie 延长至 30 天，返回 204。前端认证成功后、认证查询重新成功时以及每小时调用。这样只浏览 Memo 的活跃设备仍可续期，GET 不修改数据库。

所有 Cookie（包括 localhost）保持 `__Host-`、Secure、HttpOnly、Path=/、SameSite=Strict，无 Domain；不降级生产安全配置。生产前后端应使用同一 site 下的 HTTPS 域名。

## 前端布局与交互（2026-09-10 重构）

- 使用 Ant Design `Grid.useBreakpoint()` 决定唯一布局模式：桌面（xl）显示标签、列表、详情三栏；平板（md）显示列表与详情，标签进入侧边抽屉；手机只显示列表，详情使用全屏抽屉。
- 顶部搜索区与列表底部分页固定，标签、列表、详情独立滚动。长标题、标签和正文允许换行，不撑开栏宽。
- 桌面默认展示当前结果中的第一条记录，列表明确显示当前选中项；筛选结果变化后从当前结果派生详情，避免引用旧记录。
- 标签、详情、编辑由一个互斥的抽屉状态管理。手机从详情进入编辑，取消后返回详情；切换到桌面时关闭手机详情抽屉。
- 列表保留直接复制和更多菜单，菜单提供编辑及带确认的删除。删除成功立即移除缓存中的记录；删除当前页最后一条时返回上一页。
- 搜索输入保留 150ms 防抖，浏览器前进／后退会取消未执行的输入更新。保存备忘录保留原搜索和标签条件。
- 关闭有修改的编辑器时确认是否放弃；刷新／关闭浏览器页面时提示未保存。保存请求期间禁止继续输入或关闭编辑器，防止丢失提交后的修改。


## 环境变量与默认跨域（2026-09-10）

- 前端通过必填 `VITE_API_BASE_URL` 确定后端地址，源码无默认服务器地址。Vite 启动／构建时校验配置，生成的 CSP 自动允许该 API Origin。
- 后端始终允许任意 Origin 和预检请求头，CORS 回显请求来源并启用凭据；不能向携带 Cookie 的请求返回字面量 `Access-Control-Allow-Origin: *`。
- 已移除 `MEMO_FRONTEND_ORIGIN` 和写请求 Origin 校验，旧环境变量不再生效。JSON Content-Type 和 `X-Memo-CSRF: 1` 校验继续保留。
- Cookie 属性不变，跨站 Cookie 限制与 CORS 是不同机制。默认开放模式不再提供 Origin 白名单限制。
- 详细文档统一位于 `docs/`，根目录 README 仅保留简介、快速启动与文档入口。
